# THE UNIVERSAL HIVE

**Complexity Hidden. Power Delivered.**

Cross-platform Progressive Web App + Tiny Local LLM.

- Runs in any modern browser
- Installable as an app on phones and computers
- Offline-capable after first load
- **Immutable Base Seed** (only the Architect can change it)
- Pure-JS **tiny local LLM** that trains on-device (no cloud, no download)
- All agents start from Base Seed; sub-agents always born with Base only

## Live URL (GitHub Pages)

Once you enable Pages (one click):

**https://jackschitt1134.github.io/THE-UNIVERSAL-HIVE/**

### Enable GitHub Pages (30 seconds)
1. Go to the repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Save

After ~1 minute the permanent public URL will work.

## Local LLM

- Character-level seed model written in pure JavaScript
- Trains in the browser on the Base Seed corpus
- Same refusal filters (VETO / CAPTURE_LASSO)
- Works offline

Open the **LOCAL LLM** panel in the cockpit to train and chat.

| File | Purpose |
