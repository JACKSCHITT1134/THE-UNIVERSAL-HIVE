## Live

Open `index.html` directly or host it (GitHub Pages, any static host, local file, etc.).

## Install as App

1. Open the page in Chrome / Edge / Safari / Firefox on phone or desktop
2. Use the browser’s “Install” or “Add to Home Screen” option
3. It launches like a native app
